How it's safe

Honest about the limits. Exact about the guarantees.

01

Zero-knowledge server

Stores only Argon2id(authHash) and wrapped ciphertext. Never sees the master key, wrap key or plaintext vault.

02

Frictionless second factor

A password leaked from a breach cannot unlock the vault without reproducing the timing cadence of your hands.

03

Data minimization

Raw keystroke events and feature vectors are never stored or logged. Only means and floored variances remain.

04

The Rhythm Light guarantee

No capture without a visible indicator. The code throws if the light is missing or obscured.

05

No lockout by your body

Pass, amber retry, step-up via passkey / TOTP / Backup Code, and Pause mode. Fatigue or injury never locks you out.

06

Replay-resistant signing

Each device holds an Ed25519 keypair and signs nonces, timestamps and payload hashes on every request.

07

A way back in

A Recovery Kit at signup, shown once. Ten one-time Backup Codes for the smaller case: a new keyboard, a broken wrist.

08

No score, ever

You are told the band and a sentence, never a number. A live score is the one thing an attacker could tune against.

If someone watches you type in person and is very good, maybe. That is why a new device always asks for a second confirmation. The attack this defeats is the real one: a password leaked from a breach, used from somewhere else.
